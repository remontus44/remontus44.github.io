Подключение базы

Вставьте Project URL и anon public key из Supabase. Ключ публичный — заказы защищены входом по email и паролю.

Если база ещё не создана:
  1. Создайте проект на supabase.com.
  2. SQL Editor → выполните файл supabase/schema.sql.
  3. Authentication → Users → Add user: email и пароль, включите Auto Confirm.
  4. Project Settings → API → скопируйте Project URL и anon public key сюда.

Вход в базу

Заказы, статистика и акты. Вход по email и паролю мастера.
